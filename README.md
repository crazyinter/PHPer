# PHPer

**Neighbor leakage and ORF-derived coding signals in alignment-free phage-host prediction:
a controlled benchmark**

PHPer is a controlled benchmark for alignment-free prediction of the bacterial host of a phage
from its nucleotide sequence. It does not propose a larger network as the headline result. Instead
it isolates the effects that actually drive reported accuracy:

- the **data partition** is the largest effect. Under a similarity-aware split that keeps
  near-identical phages together, the full model's top-1 accuracy falls from 74.68% to 44.92%
  (a 29.76-point gap; Holm-adjusted p = 0.0033);
- a **logistic regression on the same FCGR features matches or beats every deep model**
  (82.3% / 83.6% on the two datasets), and the bidirectional Mamba2 block gives no stable gain;
- **ORF-derived coding features outperform FCGR**, and the signal survives GC residualization and
  multiple-comparison correction, while it is not explained by GC, length, or gene count;
- the two public resources **overlap heavily and do not survive sequence de-duplication**, so
  neither is treated as independent external validation;
- temperature scaling fixes over-confidence (ECE 0.729 to 0.067) and a calibrated confidence
  detects withheld hosts (AUROC 0.91-0.94).

## Datasets

| Dataset  | Phages | Host classes | Notes |
|----------|--------|--------------|-------|
| CHERRY   | 1,875  | 206          | 135 genera; 88 singleton classes; strongly imbalanced |
| DeepHost | 2,845  | 108          | 108 of 118 standard classes occupied; 10 empty classes excluded |

CHERRY curation was re-run from the original table (2,097 raw pairs; 222 missing a sequence;
157 empty-species entries) with an explicit species-only rule and no genus fallback. DeepHost is
standardized by exact-matching its 366 raw host-name strings to the 118-class reference taxonomy.
The large feature/sketch files and the pinned host reference genomes are attached to the releases;
see [`data/README.md`](data/README.md) for the file list and the generating scripts.

## Environment

Python 3.10 with the packages in `requirements.txt` (numpy, scipy, scikit-learn, pandas, matplotlib,
torch, pyrodigal, biopython, einops, python-docx, lxml, xlrd). A CUDA GPU is used for the deep

## Reproduction order

1. Build the processed data and MinHash sketches: `build_cherry.py`, `build_deephost_std.py`,
   `build_cgr3d.py`, `fcgr.py`, `splits.py`, `protein_features.py`; freeze checksums with
   `freeze_data.py`.
2. Download and pin the host reference genomes: `download_deephost_hosts.py`,
   `final_download_hosts.py`, `fetch_wgs_contigs.py`.
3. Train the deep models: `train.py`, `train_fusion.py`, `train_deephost_fusion.py`,
   `train_deephost_ce.py`, `train_phagecgrnet.py` (batch drivers: `run_*_batch.py`).
4. Train the classical baselines: `run_ml_baselines.py`.
5. Run the analyses: `build_correction_families.py`, `paired_bootstrap.py`,
   `phage_level_bootstrap.py`, `ml_tuning_sensitivity.py`, `phylogeny_control.py`,
   `dedup_transfer.py`, `representative_sensitivity.py`, `multi_seed_calibration.py`,
   `open_set_rejection.py`, `open_set_bootstrap.py`, `confounding_control.py`,
   `cross_dataset_overlap.py`, `efficiency_protocol.py`, `component_split_robustness.py`,
   `threshold_sensitivity_multi.py`, `extra_scoring.py`, `full_class_errors.py`.
6. Render the figures: `make_all_figures.py` and `make_workflow.py`.
7. Build the editable Word manuscript: `build_manuscript_v5.py`; verify numbering with
   `check_v5.py` and accessibility with `check_accessibility.py`.

## Compiling the manuscript (LaTeX)

The Frontiers project in `manuscript/latex/` is self-contained and splits into two documents that
are compiled separately: the main manuscript `frontiers.tex` and the supplementary material
`frontiers_SupplementaryMaterial.tex`. It is easiest to compile on
[Overleaf](https://www.overleaf.com): create a project, upload the whole `latex/` folder, set the
compiler to pdfLaTeX, and select the main document. For the main manuscript run
**pdfLaTeX -> BibTeX -> pdfLaTeX -> pdfLaTeX**. The supplementary document has no bibliography,
so compile it with **pdfLaTeX -> pdfLaTeX** only (set it as the main document when building its
PDF). On a local TeX Live installation the same sequences work with
`latexmk -pdf frontiers.tex` and `latexmk -pdf frontiers_SupplementaryMaterial.tex`.
The main reference style is numbered Vancouver (`FrontiersinVancouver.cls`,
`Frontiers-Vancouver.bst`); the supplementary file uses `frontiers_suppmat.cls`, which numbers
its tables and figures automatically as Table S1 and Figure S1. The main text keeps 6 figures and
9 tables (15 in total); every other item is in the supplementary document. For submission, upload
each `.tex`, its generated PDF, `references.bib`, and every figure in
`manuscript/latex/figures/`.

## Key configuration

- FCGR: k = 6 -> 64 x 64, 4,096 cells; windows with an ambiguous N are not counted but the
  denominator stays L - k + 1; no reverse-complement merging.
- Sequence encoder: two Conv2d (kernel 7, stride 2; BatchNorm + ReLU; max pool; 64 -> 128 channels),
  one bidirectional Mamba2 block, 512-d head. The CNN-only variant removes the block.
- Two independent pipelines share one architecture (`results/method_config.json`): the default
  contrastive pipeline (`results/pipeline_contrastive.json`) has no head and uses the matrix
  contrastive loss with Euclidean distance plus three BN recalibration passes; the cross-entropy
  pipeline (`results/pipeline_ce.json`) adds a Linear(512, n_hosts) full-host softmax head.
- ORF-derived coding features: 96 dimensions = 8 structural + 64 codon + 20 amino-acid +
  4 physicochemical; ORFs are called with `pyrodigal.GeneFinder(meta=True)`, translation table 11,
  separately on each contig.
- Training: Adam, lr 1e-3, no weight decay, full FP32, 120 epochs (100 fusion), batch 32, best
  validation checkpoint. Seeds: 123, 2024, 42, 7, 99.
- One global correction family of m = 13 tests with Holm (family-wise) and Benjamini-Hochberg
  (false-discovery) adjustment; the full unrounded list is in `results/correction_full_list.csv`.
  The fixed-split permutation contrasts are labelled exploratory and are kept outside this family.

## Statistical note

Seeds quantify training stability under different initializations and data orders; they are not
independent biological replicates, so seed-level t-tests and Cohen's d are descriptive. Phage-level
inference uses a 2,000-resample paired bootstrap (percentile 95% interval) and a sign-flip
permutation. A non-significant result means the present data do not provide evidence for an effect;
with few seeds it is not evidence that no effect exists. Codon usage is described as predictive and
consistent with, but not proof of, translational adaptation.
